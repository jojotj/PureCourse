# 16 · 本地存储（U 盘）交付说明

版本：`1.0.0-tv9.16`（versionCode 27）　日期：2026-11-08

---

## 一、这一版做了什么

### 1. 本地存储不再是一条"特殊数据源"，而是一等公民

**一个挂载点 = 一条数据源**。内置存储固定一条（id `l0`），每个 U 盘 / SD 卡各一条（id 由卷 UUID 派生）。
它们和 SMB、WebDAV 走**同一套**：左树第一层、右栏、加书架、收藏、备注名、书架来源角标、播放。

所以你看到的就是：

```
左树第一层
├── 本地存储        ← 内置存储 /storage/emulated/0
├── U盘 · SanDisk   ← 插了几个盘就有几行
├── 本机SMB
└── 115网盘
```

**为什么这样设计**：你说过"将来要改成平板 / 手机端，逻辑不能变"。
把挂载点做成普通数据源、复用现有多源管线，比给本地存储单开一个页面更能保证这一点 ——
以后加 SD 卡、加移动硬盘，只是多一条 Cfg，UI 一行不用改。

### 2. 扫描规则与 SMB 完全一致

`RealCatalog` 里把"怎么列一层目录"抽成一个出口（`entriesOf`），SMB 用 `SmbSession`，
本地用 `LocalStore.entries`（`File.listFiles`）。**课程识别、集数自然排序、节点构建是同一段代码**：

- 一级子目录里直接含视频 → 一门课
- 挂载点根自己就是一摞视频 → 根本身算一门课
- 支持 `.flv/.mp4/.mkv/.avi/.ts/.wmv/.mov/.m4v/.webm/.rmvb/.mp3/.m4a/.wav`
- 跳过系统垃圾目录：`Android`、`LOST.DIR`、`$RECYCLE.BIN`、`System Volume Information`、`.` 开头

### 3. 播放走 `file://` → FileDataSource

`SourceRoutingFactory` 新增 `file` 分支；`Cfg.uriOf` 用 `Uri.fromFile` 生成，
中文 / 空格 / 括号自动编码（手拼 `"file://" + path` 会让 `第1节：xxx.mp4` 直接播不了）。

### 4. 权限

| 系统 | 权限 | 说明 |
|---|---|---|
| Android 11+ | `MANAGE_EXTERNAL_STORAGE` | 分区存储下 `File.listFiles()` 会返回 null，只有它能按路径遍历 |
| Android 10 及以下 | `READ_EXTERNAL_STORAGE`（启动时申请） | 老设备没有上面那个开关 |
| Android 10 | `requestLegacyExternalStorage` | 兼容老的分区存储行为 |

数据源页的本地卡片在未授权时**明确写**「未授权 · 点此开启「所有文件访问权限」」，
点它直接跳系统授权页；从授权页返回时 `onResume` 会自动重新探测，不用重启应用。

### 5. U 盘热插拔

动态注册 `ACTION_MEDIA_MOUNTED / UNMOUNTED / EJECT / REMOVED`，
插拔后**只重扫本地**（`refreshLocalSources`），不会把 115 网盘整棵树重扫几分钟。

## 三、自查时发现并修掉的 4 个 bug（都是我这版自己引入或此前埋着的）

1. **本地视频一播就黑屏** —— `Media3Engine.open()` 只把 `smb://` / `http` 当完整 URI，
   其余一律 `Uri.fromFile(File(uri))`。于是 `file:///storage/...` 被当成**裸路径**又包了一层，
   变成 `file://file:/storage/...`，报 `FileNotFoundException: /file:/storage/...`。
   实测抓到了这条日志才定位到。

2. **播放页取不到本地源配置** —— `resolvePlaySource()` 用 `SourceStore.get(id)` 反查，
   而本地源**不落库**（拔盘即消失，不留死配置），永远查不到 → 片源=null。
   改为优先查内存里的 `sourceCfgs`。

3. **「添加数据源」里多出一个「本地存储」协议** —— `Proto.entries` 现在有三个值，
   添加页和按键路由都直接用了它。本地存储不需要填地址账号，出现在那里只会让用户点进一个填不了的表单。
   新增 `Proto.selectable`（排除 LOCAL），页面和路由都改用它。

4. **Android 10 及以下读不到 U 盘** —— 只声明了 `READ_EXTERNAL_STORAGE` 却没申请运行时权限，
   这类设备上会显示空目录，用户完全看不出是权限问题。已在 `MainActivity.onCreate` 申请。

另外顺手补的两处：本地卡片增加"读取异常"提示；`refreshLocalSources` 拔盘后立刻丢掉该源快照
（否则书架会继续挂着"已经不存在的课"）。

## 四、遗留与风险（没修 / 没验证，不粉饰）

| 项 | 状态 |
|---|---|
| **多个 U 盘并排** | 代码按卷 UUID 生成 id、同名自动加序号，但**模拟器无法构造第二个挂载点**（`/storage` 只读、无 root），**未实测**。需要你插一个真实 U 盘确认 |
| **U 盘热插拔** | 广播已注册、重扫逻辑已写，但模拟器没有可插拔卷，**未实测** |
| **真机 `MANAGE_EXTERNAL_STORAGE`** | 电视固件可能没有「所有文件访问权限」这个设置页（部分厂商裁剪）。跳转失败时会提示去系统设置手动开，但**没有真机走过这条路** |
| **内置存储会扫出无关视频** | 一级子目录里含视频就当课程，所以 `DCIM/Camera`、`Download` 里的视频也会变成课程。可以用书架卡片菜单「移出书架」清掉，但**首次启动会比较吵** |
| **U 盘拔掉后课程消失** | 设计如此（不落缓存，避免"盘拔了课还挂着"）。插回同一根盘、同路径时收藏 / 书架 / 续播会恢复（id 由 UUID 派生，稳定） |
| **备注名中文** | 仍依赖电视输入法，adb 输不了中文，实测用的是英文名 |
| **本地源不走缓存** | 每次启动实时读盘（内部存储约 1~2 秒）。好处是准确，坏处是超大文件夹在低端电视上可能慢 |
