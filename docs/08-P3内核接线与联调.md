## 3. 当前卡点：模拟器到宿主的 445 不通

探测结果：

```
ping 10.0.2.2        → 通（0.29ms）
SMB 协商包 → 445     → 无任何响应（0 字节）
本机共享             → 存在：课程共享 → L:\课程共享，另有 临时 / 学习资料/ 舞蹈共享
本机 445             → 0.0.0.0:445 LISTENING
```

结论：**Windows 防火墙拦了入站 445**（默认只对"专用网络"放行），不是共享没开。
这一步要改系统设置，我不擅自做。放行命令（管理员 PowerShell）：

```powershell
New-NetFirewallRule -DisplayName "SMB 445 (LAN)" -Direction Inbound `
  -Protocol TCP -LocalPort 445 -Action Allow -Profile Private
```

放行后我就能联调：连 `10.0.2.2` / 共享 `课程共享` / 账号 `guest`，跑目录列举与播放。

## 5. 关于"为什么要自写 DataSource"

SMB 是随机访问协议：smbj 的 `File.read(buffer, fileOffset)` 可以直接按偏移读。
所以 Media3 seek 时不需要"重开文件、丢弃前 N 字节"，这也是选 Media3 + 自写 DataSource
而不是"先整段下载到本地"的原因（后者对 1GB 的课程视频不可接受）。
