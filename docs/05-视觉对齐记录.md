# 05 · 视觉对齐记录（可复跑）

## 1. 为什么要这么做

"一模一样"不能靠肉眼说。做法是：**先抓到原型的机器可读基准，再逐项比对数值**。

```
puppeteer（Chrome headless，1920×1080，deviceScaleFactor=1）
  ├─ 逐页截图               → docs/ref-01..11-*.png
  ├─ 关键元素盒模型导出      → docs/ref-01-metrics.json
  └─ 各页关键元素盒模型      → docs/ref-pages-metrics.json
adb exec-out screencap      → docs/app-01..11-*.png（同页同分辨率）
```

导出内容包含 `x / y / w / h / font-size / font-weight / padding / gap / border-radius`，
所以"差 8px"这种问题可以直接被判出来，不用来回猜。

## 2.5 焦点环专项返工（2026-11-04，老板实测反馈）

现象：① 设置行/数据源卡的圈"套歪了"，和卡片不贴合；② 数据源第一张卡的圈上边被切掉。

根因三条，全部是画法问题，不是数值问题：

| # | 根因 | 表现 |
|---|---|---|
| 1 | 用 `drawBehind` 画环 → 被组件自己的 `background` 盖住 | 只剩向外扩的那一截，看起来像"外套了个圈" |
| 2 | 环画在边界**之外**（照搬 CSS `box-shadow` 的外扩语义） | 首行/首列被 `LazyColumn`/`LazyVerticalGrid` 的滚动裁剪切掉上边或左边 |
| 3 | 圆角写成 `radius + inflate` | 四角向外鼓，和卡片圆角对不上 |

修法：改用 `drawWithContent`（先画内容再画环）＋ **向内描 3px** ＋ 圆角不放大；
并按原型逐个组件核对"有没有环、要不要缩放"（`.srow/.srccard` 不缩放，`.book` 1.035、`.epc` 1.05、`.pm` 1.04……）。

连带修掉两个：
- 播放进度条的环向内后会吃掉轨道（14dp 被覆盖 3px）→ 容器改为 20dp，轨道上下各留 3dp 给环；
- 焦点柔光在**细小控件**上会盖满整条 → 加尺寸门槛（宽 >120dp 且高 >40dp 才画柔光），否则进度条未播放段会发橙。

## 2.6 第二轮实测反馈修订（2026-11-04 下午）

| # | 反馈 | 根因 | 修法 |
|---|---|---|---|
| 1 | 进度条整条高亮太丑，只要小球亮；球太大；有两条线穿球 | 焦点环套在 20dp 容器上（16dp 环 + 轨道被压）；描边圆直径 > 白球，圆弧与轨道交叉形成"线" | 去掉整条环；球 9dp→获焦 11dp（比原型的 1.5 倍克制）；白球不透明盖住轨道，橙边描在**球内侧**，不再有线条；容器 28dp 容纳放大后的球 |
| 2 | 自定义倍速的球没对上轨道 | 偏移写死 `756dp`，但内容宽只有 `760-52×2=656dp` | 用 `BoxWithConstraints` 取真实宽度算偏移 |
| 3 | 开镜像看不到变化 | 镜像只挂在（尚不存在的）视频表面，占位画面没跟着翻转 | 镜像同时作用于画面区占位层，遥控器一按就能看到「高数」反向 |
| 4 | 所有课程共用一个播放进度 | `curSec` 是全局单值 | 改成 `resumeMap["courseId:ep"]`，进播放页读取、切集/退出写回（P1 换 Room `Resume`） |
| 5 | 文件夹弹窗标题串到某一节课 | 弹窗从"当前树状态"取名字，打开后树变化就取错 | 打开弹窗时把标题/副标题/两个动作可用性做快照 |
| 6 | 已在书架/已收藏的按钮应置灰且焦点到不了 | 之前只改文案不拦焦点 | 置灰样式 + 导航表里只登记"可用项"，方向键天然跳过 |

## 3. 当前残留偏差（可接受 / 待后续）

| 项 | 偏差 | 说明 |
|---|---|---|
| 字体度量 | 中文行高略有差异（约 1~3px/行） | 原型用系统字体 + CSS `line-height:normal`，Android 默认字体度量不同；已按 `size*1.25` 近似 |
| 焦点外发光 | 用三层描边模拟 `box-shadow` | Compose 无 box-shadow；三层 alpha 递减 92%/22%/9%，肉眼等价 |
| 卡片高度 | 约 ±3px | 由字体度量差异累积；不影响行距与列宽 |
| 收藏左树/右列行高 | ±2px | 同字体度量 |
| 播放画面区 | 占位（渐变 + 课程缩写水印） | P3 接真实解码后替换 |

> 判定标准：**布局骨架（x/y/宽/列数/间距/字号/圆角/颜色）必须逐项对上**；
> 字体渲染造成的 1~3px 行高差不算偏差，因为换设备就会变。
