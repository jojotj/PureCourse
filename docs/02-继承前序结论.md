## 与原型的两处**有意差异**（都是把原型的 bug 修掉，不是改设计）

1. **数据源卡片 ↓ 的落点**：原型 `srcGridDown` 用 `i*3` 取操作按钮下标，但 srcgrid 里本地卡占了
   第 0 位，导致整体错位一格。本工程改为"落到本卡自己的第一个操作"（本地卡无操作则不动）。
2. **顶栏 Tab 的 120ms 计时器**：原型虽然写了 `if (!isSet && page !== 'home') return`，
   但同类逻辑在别处仍残留"切页把页面弹回首页"的风险。本工程把规则收紧为
   **焦点驻留切页只在首页生效**，详情/浏览/播放/设置页一律不响应（对应验收项"秒退秒进不弹回 home"）。
