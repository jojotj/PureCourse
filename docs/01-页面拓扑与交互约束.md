# 01 · 页面拓扑与交互约束（接手方复述）

> 这份文档是"我理解对了没有"的自证：把原型的页面树、键位、状态纪律逐条写死，
> 后面所有代码都以它为准。有冲突时**以 `merged-shelf-list.html` 为准**，本文只是提炼。

## 1. 页面拓扑（7 页 + 5 个弹层）

```
page-home（顶栏：书架 / 收藏 / 设置）
 ├─ page-detail    课程详情（12 节目录）
 ├─ page-browse    目录逐层浏览（左目录树 + 右条目）
 ├─ page-player    全屏播放（两种态）
 ├─ page-settings  设置（5 分组）
 │   └─ page-sources  数据源管理（本地 + SMB/DAV/FTP/NFS）
 │        └─ page-addsrc 添加数据源（协议卡 → 表单 → 测试连接，3 步）
 └─ 顶栏「设置」→ page-settings（与两个 Tab 同级入口）

弹层：#multibar 多选条 / #cfm 二次确认 / #smbdiag 连接诊断 /
      #fpop 文件夹操作小框 / #p-fail 播放读取失败层 / #toast 轻提示
```

导航语义：
- **进入页面**：先取"上次离开该页时记的落点"，再把本次发起控件记为该页来源 → 新工程用
  `origin[route]` + 每页 `defaultFocus()` 实现；首次进入用默认落点。
- **顶栏 Tab「焦点到达即切页」**：120ms 防抖；**切页前必须校验当前页面**，
  残留计时器不允许把详情 / 播放 / 设置页弹回首页（原型踩过，见 KeyRouter 里的注释）。

## 2. 返回键分级（从高到低，必须严格按这个顺序）

1. 诊断层 → `先关掉`
2. 文件夹小框 → 关闭
3. 二次确认 → 取消
4. 设置项调整态 → 取消并还原原值
5. 表单编辑态 → 退出编辑
6. 多选态 → 退出多选
7. 取消收藏态 → 退出选择
8. 播放页：读取失败层 → 回课程；控制层 → 收起；否则 → 详情页
9. 详情页 → 首页
10. 浏览页 → 逐层上跳，到根回入口页
11. 添加数据源 → 步骤 3→2→1→数据源页
12. 数据源页 → 设置页
13. 设置页 → 回原 Tab（书架 / 收藏）
14. 首页收藏页：右列 → 左树；左树已展开 → 先收起；否则回上层
15. 首页书架页 → 退出应用

## 3. 遥控器五键

| 键 | 通用 | 播放页・全屏态 | 播放页・控制层态 |
|---|---|---|---|
| ↑ | 上移 | — | 切到上一个控件（在进度条上时无效） |
| ↓ | 下移 | **调出控制层** | 下移 |
| ← → | 左右移 | 快退 / 快进 `seekstep` 秒（默认 10） | 焦点移动；在进度条上时按 60 秒快移 |
| 确认 | 执行 | 播放 / 暂停 | 执行当前焦点控件（在进度条上 = 收起面板） |
| 返回 | 见 §2 | 回详情页 | 收起控制层 |

长按（≥800ms）只做**快捷方式**：
- 书架卡片长按 → 进多选（但右侧永远有「选择/移除」显式入口）
- 数据源卡片长按 → 焦点跳到该卡的「编辑」并提示三选一（卡片下方本来就有三个按钮）

## 4. 逐页要点（数值以 CSS 为准）

### 书架页
- hero：最近播放课程，`height 200`、封面 `252×142`、`第 N 节 / 共 12 节`、进度条、`▶ 继续播放 第 N 节`
- hero 右侧常驻 `132` 宽的「选择 / 移除」按钮（多选唯一显式入口）
- 书架墙：**每行 6 个**、`gap 42`、行距 `30`、木板 `height 9 / margin-top 18`、封面 `16:9`
- 卡片：左上缩写、右上 `12 节`、左上绿标 `✓ 3/12`、名称、`已看 3 节 / 共 12 节`、
  `最近播放 · 今天 20:14`、进度条
- 排序：最近播放（`lastAt` 降序，默认）/ 名称（拼音升序），在 设置→书架

### 详情页
- 左栏 `560`：封面 `330`（16:9）、课程名、`共 12 节 / 已看 3 节 / 总计 9 小时 20 分 / 1920×1080`、
  进度条、`已看 25% · 上次看到 第 3 讲 核心公式推导`、主按钮 `继续播放 第 N 节`、次按钮 `返回书架`
- 右栏 4 列剧集，已看绿 / 当前橙 / 未看暗

### 浏览页
- 左 `452` 目录树（收藏与 SMB 根）；右：面包屑 → 标题（N 个文件夹 · M 个视频文件）→ 条目行
- 每行右侧两个操作：`＋ 书架` / `☆ 收藏`（**这是"加入书架"的第二条通道，不是装饰**）
- 文件夹行确认 → 进入；课程目录 → 详情页；视频 → 播放页

### 收藏页
- 固定双栏（左 37% 树 + 右内容），**无模式切换按钮**
- 左树从收藏顶层项开始平铺，可逐层展开；`→` 进右侧内容，`←` 收起 / 回上层
- 右列内容跟随左树选中节点（不是永远显示"我的收藏"）
- 底部常驻「☑ 取消收藏」长条 → 进入选择态：每项左侧复选框 + 「全选」+「取消收藏 · N」
- **只有收藏顶层项可勾选**，收藏目录内部的子文件夹不可勾选（虚线框占位）
- 右列文件夹确认 → 小框：`＋ 加入书架` / `☆ 收藏当前`（已加过则置灰并说明原因）

### 设置页
- 5 分组：数据源 / 播放 / 字幕 / 书架 / 关于
- 行高 60，右侧值胶囊；开关 62×32
- **多档调整态**：确认进入 → ←/→ 逐档切换并实时预览 → 确认落库 / 返回还原；调整态中上下键失效
- 倍速必须存原始值（原型曾因 `Math.round` 把 0.75 存成 0.8）

### 数据源页
- 首卡固定「本地数据」，其后网络源卡（名称 / 协议角标 / host:port·path / 状态点）
- 每卡下方 3 个操作：编辑 / 重连 / 删除（删除走二次确认）
- 状态三态：`已连接 · N 个顶层目录` / `连接被拒 · 电脑共享连接数已满` / `连接失败 · 检查网络与账号`
- 「重连」若上次是 `err=full`，**先弹诊断层**，不无脑重试

### 添加数据源
- 步骤 1 协议卡（SMB 445 / DAV 443 / FTP 21 / NFS 2049）
- 步骤 2 表单（主机/端口/路径/账号/密码 + 记住）+ 局域网发现 + 最近使用
- 步骤 3 测试连接（转圈 → 成功 / 失败带错误码）
- 保存后回数据源页，新卡片有一次脉冲高亮

### 播放页
- 全屏态：无任何控件、顶栏整条隐藏
- 控制层态：顶部课程名 + 副标题、进度条、时间行、5 个菜单按钮、提示行
- 暂停符：`left 64 / top 150`，两根 `11×49` 圆角 4 竖条，`rgba(255,255,255,.46)`；
  控制层展开时 `top 246` 且透明度 `.72`
- 右上角时长 OSD：`right 56 / top 112`，快移时显示 **1 秒**；
  **全屏态与控制层态必须同一套逻辑**（原型曾因控制层态被强制清掉导致看不到时长）
- 倍速：菜单（0.75/1.0/1.25/1.5/2.0 + 自定义）；自定义 `←/→` 每档 0.05，范围 0.2–3.0
- 镜像 `scaleX(-1)`、单曲循环、上一节/下一节
- 离开播放页必须清 `loop / 倍速菜单 / 自定义框` 三个状态

## 5. SMB 连接数上限（硬需求，不能省）

Windows 自带共享最多 20 条并发会话。软件必须**明确告知是连接数问题**，不能无声假死。

4 个触发点：
1. 进播放页 → 若会话满，直接出「读取失败层」，不显示暂停符、不假装在播
2. 失败层「重试读取」→ 第 1 次失败 toast「还是被拒：电脑那边的会话没清」；**第 2 次失败自动升级到诊断层**
3. 数据源页「重连」→ 该源上次是 `err=full` 时先弹诊断层
4. 设置 →「SMB 连接诊断」→ 常驻入口，右侧实时显示 `当前：连接数已满` / `20 条上限 · 查看`

工程纪律（否则照样被占满）：
- 浏览与播放**共用一条会话**（单例），失败**指数退避**（1/2/4s，上限 3 次），禁自动狂重连
- 播放器关闭 / 切集 / 退出播放页 → 主动 `session.close()`
- 错误分类：`ConnectException/NoRouteToHost` → 网络；`SmbAuthException` 但密码无误 /
  `STATUS_REQUEST_NOT_ACCEPTED` / `0xC00000C9` → 会话满；读 0 字节 / 中途断流 → 会话满
