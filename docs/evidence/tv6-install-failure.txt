tv6 U 盘安装失败排查记录（2026-11-06 17:09~17:15）
结论：APK 构建产物没有问题；U 盘上那份文件在 classes.dex 内有
      一个 8 KiB 块损坏，导致验签失败、安装器秒退。
================================================================

1. 现象
----------------------------------------------------------------
用户用 U 盘在 TCL 电视（192.168.1.10）安装 tv6，系统安装器弹出
「安装失败」。同一时间窗内用户连续尝试 3 次，均失败。
电视当前仍是 tv5：versionCode=5 / 1.0.0-tv5 / lastUpdateTime=2026-11-05 20:14:14
设备侧签名：signatures=PackageSignatures{e3db520 version:2, signatures:[6cc72e45]}

来源 URI（logcat 实证，17:09:11.681）：
  content://com.tcl.tguard.fileprovider/root_path/storage/2AF1-247A/
  课程库-1.0-TV-tv6(装这个).apk
  ⇒ 拿的确实是中文交付包名，不是 arm64-v8a / x86_64 包，排除拿错 ABI 包。

3. 已排除的可能原因（逐项有证据）
----------------------------------------------------------------
  * 签名证书不一致：tv5 与 tv6 证书 SHA-256 完全相同
      ce5f17d1c2d5fea12d4d880bb4c8b555ee8ac8c0d0ea194f829edbdedb82b65e
    DN = CN=ChunTing CoursePlayer，同一 keystore/courseplayer.jks
    （2026-11-04 00:59 创建，未变）。
  * 版本降级：versionCode 5 → 6，versionName 1.0.0-tv5 → 1.0.0-tv6，正常升级。
  * v1 签名缺失：两包 apksigner verify 均 v1=true / v2=true；TCL 只认 v1 的坑已排除。
  * 清单差异：包名 com.chunting.purecourse、minSdk 21、targetSdk 34、
    权限 / uses-feature / native-code=armeabi-v7a 两包完全一致；
    unzip -Z1 文件清单 diff 无差异。
  * 拿错 ABI 包：见 §1 的 content URI。
  * 存储空间不足：dumpsys diskstats → Data-Free 44770892K / 52167164K（85% free）。
  * 文件名含中文/括号：tv5 同格式文件名在 11-05 20:14 同通道装成功。
  * 本地 APK 自身损坏：unzip -t 无错误，python zipfile.testzip() = None，
    apksigner verify exit=0。

5. 为什么表现为 472 ms 秒失败
----------------------------------------------------------------
APK 头部与前面部分未坏，所以安装器能读出包名/图标并弹确认框；
一旦校验到 classes.dex 的损坏块，v1 摘要 / v2 CHUNKED_SHA256 立即不匹配，
安装在安装会话提交阶段被打回，PackageManager 里因此没有任何安装记录。
三次尝试用的是同一份损坏文件，所以三次都失败。

6. 处置（未改动任何源码，未重出包）
----------------------------------------------------------------
  新增一个文件名更短、不易与旧包混淆的干净副本：
    dist/CourseTV-tv6.apk
    12494848 B
    MD5     863409670fac8d30ebfad9372aa40934
    SHA-256 80d817dc8f8ef5bf1d16bd8bfeb37fd899312dfd2b9ae96fba144934daa78bf7
    与 dist/课程库-1.0-TV-tv6(装这个).apk 经 cmp 逐字节一致，v1+v2 验签通过。

  用户操作：删除 U 盘上旧的 tv6 文件 → 重新拷贝 CourseTV-tv6.apk →
  在电脑上核对哈希 → 安全弹出 → U 盘装电视。
  电脑侧核对（PowerShell）：
    Get-FileHash <U盘盘符>:\CourseTV-tv6.apk -Algorithm SHA256
  必须等于 80d817dc8f8ef5bf1d16bd8bfeb37fd899312dfd2b9ae96fba144934daa78bf7。
  若重拷后仍不等：换 U 盘 / 重新格式化 / 换电视 USB 口，属介质问题。

  不需要先卸载 tv5：签名证书一致、versionCode 6 > 5，属正常覆盖升级。
