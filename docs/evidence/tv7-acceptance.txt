0. 本轮用户需求（三条）
----------------------------------------------------------------
  ① 不需要跨课程播放：一门课程播完，弹回播放前的界面即可。
  ② 遥控器不够跟手，审查整体代码与结构，重点优化收藏页。
  ③ 参考获奖 App（尤其 iOS）的 UI，只改视觉（配色 / 选框 / 高亮 /
     字体 / 浮窗等），不改页面架构与交互逻辑。

1. 片尾行为：取消跨课程，改为「弹回播放前的界面」
----------------------------------------------------------------
  代码（AppState.kt）：
    - 新增 playerFrom：go(Page.Player) 时记录来源页（Home / Detail），
      不再像原来那样一律回详情页。
    - onPlaybackEnded() 分支改为：
        loop                      → 交给 PlayerPage seekToMs(0)
        autoNext && curEp < n     → stepEp(1)        （同课程内自动下一节，保留）
        contPlay                  → leavePlayerAfterEnd()
        否则                       → playing = false（停在片尾）
    - 新增 leavePlayerAfterEnd()：标记本集已看 → go(来源页, record=false,
      noRecall=true) → 还原进入播放页时的焦点（hero / dact:N / ep:N）。

      详情页的来源记录，污染下一次返回落点。
    - 设置项文案：「连续播放 / 列表播完自动接续下一个视频」
                    → 「播完返回 / 整门课播完后回到进入播放前的页面」。

    回到书架 → OK 进播放 → DOWN 开控制层 → 7 次 60 秒快移越过片尾。

    ⇒ 命中片尾后只处理一次（handled），且不跨课程。

2. 遥控器跟手性：定位到 4 个根因（其中一个是功能性死角）
----------------------------------------------------------------
  2.1 每次方向键重复构建整张区域表（主因）
      原链路：nav() 调 buildRegions() → regionOf() 又调一次
              → setFocus()→containsTag() 再调一次。
      收藏页每次构建都递归 ftRows()，并对每个节点反复调 mcItems()。
      ⇒ 一次按键 = 2~3 次整树重建。
  2.2 do 收藏页区域表与界面用的不是同一份列表（功能性死角）
      buildRegions 里 fplist 用 AppState.ftKey，而进入收藏页时 ftKey 仍是
      "#fav"（只有 1 项）；界面 FavPage 用的是 rows[ftSel].key（13 项）。
      ⇒ 区域表里只有 fpl:0，按 DOWN 时
         ftRow+1 < mcItems(ftKey).size 恒为 1<1=false，被判成「没有下一项」，
         右侧列表方向键**完全动不了**（用户感受就是卡死）。
      实证：tv7-fav-12down.png（修复前：连按 12 次 DOWN，焦点仍在第 1 行、
            列表没滚动）。
  2.3 焦点移动时无条件播放滚动动画
      五个页面都在 LaunchedEffect(focusTag) 里 animateScrollToItem，
      焦点项本来就在可视区也会起 spring 动画，连按互相打断 → 视觉滞后。
  2.4 LazyColumn 列表项没有稳定 key，焦点变化时整屏可见项重建。

  2.5 修复
      a) buildRegions() 按 regionsSignature() 缓存（签名只含「会改变可聚焦项
         集合」的状态，焦点本身不在签名内），命中直接复用。
      b) nav() 复用同一份 regions，不再调 regionOf() 二次构建；
         setFocus() 对「同 tag」短路，且收藏页 ft: 焦点变化时同步
         ftSel / ftKey / ftRow——左右两栏永远同一份列表。
      c) ftRows() 与 mcItems() 加签名缓存；ftToggle 切目录时重置 ftRow。
      d) 新增 LazyListState/LazyGridState.ensureIndexVisible()：焦点项已可见
         就一动不动；不可见才 scrollToItem（无动画），且只滚最小距离。
      e) FavPage / ShelfPage 的 items 加稳定 key。
      f) Txt 的 TextStyle 按参数 remember；tvFocus 的 scale 只在真变化时写 layer。

  2.6 实测
      修复后同一操作（RIGHT 进右列表 + 12 次 DOWN，间隔 120ms）：
        tv7-fav-12down-fixed.png / tv7-fav-final.png
        右侧列表已滚到「（初级）(3878)」及后续项，焦点随之移动。
      Choreographer「Skipped N frames」计数 = 0；无 ANR、无崩溃。
      如实边界：MuMu 的 dumpsys gfxinfo 只统计到 1 帧（模拟器渲染路径不经过
      HWUI 帧统计），所以没有拿帧耗时当指标，改用「焦点是否真的移动/滚动」
      与 Choreographer 丢帧告警作为可核验证据。

3. UI 视觉升级（只改视觉，不动页面结构与导航）
----------------------------------------------------------------
  3.1 设计令牌（core/Dims.kt 重写）
      - 背景/面板改为中性深色层级：Bg #0A0909、Panel #16151A、
        Panel2 #1D1C22、PanelHi #27252D（原来是暖棕系，显脏）。
      - 文字四级：Text #F6F3EF / TextSoft / Dim #A09890 / Dim2 #746D66。
      - 描边统一白色低透明度：Line 7% / Line2 13% / Line3 23%。
      - 焦点态改为「白色 2.5dp 硬环 + 品牌橙内光晕」；原来只有橙色粗描边。
        圆角不再随外扩量放大；不做真实 blur（TV GPU 上开模糊会让按键变粘）。
      - 品牌橙保留，渐变改为 AccDeep(#E9662B) → Acc(#FF8E52) → Acc2(#FFC49A)。
  3.2 顶栏：深色玻璃渐变 + 底部细线；书架/收藏/设置改成白色胶囊 tab，
      聚焦直接反白（iOS segmented control 的选中语义），不再用橙色描边框。
  3.3 书架：Hero 圆角 20、四段暖光渐变；主按钮改为白色实底 + 深字
      （Apple TV 首页「继续观看」的做法）；课程卡改实体 Panel + 1dp 细描边 +
      圆角 16；层板从暖棕木纹改成暗色实体层板 + 1px 高光线。
  3.4 收藏：左树行圆角 12、焦点淡品牌底 + 白环；复选框改渐变胶囊；
      右列表改实体面板行；「⋯」按钮改中性面板；底部按钮改胶囊、主操作反白。
  3.5 详情：封面圆角 14、集数卡圆角 12 + 1dp 细描边（当前集暖橙、已看绿）；
      主按钮橙渐变 18 圆角，次按钮改中性面板。
  3.6 设置：去掉「橙色粗边 + 1dp 边 + 焦点底」三层叠加，只留焦点底色 + 白环；
      开关改渐变；值胶囊圆角 12；说明文字从 Dim2 提到 Dim（可读性）。
  3.7 数据源 / 添加数据源 / 浏览：卡片圆角 14→18、行 9→12、
      焦点底统一 AccSoft，焦点边框交给白环。
  3.8 弹层（多选条 / 文件夹小框 / 二次确认 / SMB 诊断 / Toast）：
      统一深色磨砂卡片（圆角 22~24）+ 白色低透明描边；按钮全部胶囊化；
      确认框的危险操作聚焦时用红色实底反白。
  3.9 播放页控制层：进度条三段渐变 + 球体柔光；五个按钮改圆角 16、
      焦点白底反白、激活态品牌淡底；倍速菜单与自定义倍速弹窗统一深色卡片。
