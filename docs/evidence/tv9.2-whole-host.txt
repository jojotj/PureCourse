tv9.2 · 整机模式（一个 IP = 一个数据源，所有共享进目录树）
================================================================

一、用户原始诉求（原话）
------------------------
「现在四个都能读出来，但逻辑太复杂：读出来以后右边只能选其中一个，IP 固定时前端也只能显示
一个数据库，每次改数据库都要回编辑里换共享目录。应该不用我选，跳出来就是所有共享目录在
左边，我左边可以浏览目录，右边可以把某一个子目录或根目录添加到收藏或书架。」

「你数据源点进去，假设我现在是 SMB 共享，那左边的目录数就应该有我共享的 4 个目录啊。」

二、模型变更
------------
旧：一个数据源 = 一个共享（share + root），浏览树只有一个根。
新：**整机模式**。`SourceStore.Cfg.share` 留空 ⇒ `wholeHost = true`，
    一个 IP 就是一个数据源，服务端枚举出的每个共享都是浏览根。

统一路径语义：`共享名\子目录\...`（整机模式）。
`Cfg.splitRel(rel)` 负责拆成「共享 + 共享内路径」，会话层用 `listIn(share, inner)`
在共享之间自动切换（`useShareLocked`），上层浏览/书架/播放都不用关心共享边界。

三、必须解决的三个并发/持久化问题（都是实测暴露出来的）
--------------------------------------------------------
1. **共享句柄被多线程抢用** → 深层目录偶发「空目录」。
   修：`SmbSession` 所有 IO 走同一把 `ioLock`，并新增原子方法 `listIn(share, path)`
   （切共享 + 列目录在同一锁内完成，不再有 useShare→list 的空窗）。
   同时 `connect` 也进锁 —— 之前两个线程并发 connect，建两条会话互相覆盖。

2. **会话被判死后再不自愈** → 深层下钻一直「正在读取」。
   修：`isConnected` 改为看底层连接可达性；`list/listIn` 失败后强制
   `closeQuietlyInner()` + `reconnectLocked()` 重试一次。
   另把 `soTimeout` 从 20s 放宽到 120s（浏览是人的操作节奏，20 秒不动就被判超时）。

3. **`STATUS_PIPE_NOT_AVAILABLE`** → srvsvc 管道瞬时不可用，共享枚举失败并连带
   「加入书架」失败。修：枚举带重试。

四、持久化（两处硬伤，都是"看着成功、重启就没"）
------------------------------------------------
1. **收藏只存内存**：电视上按一次 Home 被回收就全丢，收藏页只剩自动生成的根。
   修：`SourceStore.favPaths/addFavPath/removeFavPath`，格式 `rel<TAB>name`。
   冷启动扫描后与根节点合并重建 favs。
   顺带：行内「☆ 收藏」按一下收藏、再按一下取消（不再弹"已在收藏中"），
   按钮文案回显「★ 已收藏」。

2. **播放状态（lastAt / 上次第几节）没落盘**：每次冷启动都退回「尚未播放」，
   「继续学习」只能取扫描顺序第一门。
   修：新增 `CourseMetaStore`（key = 目录路径，**不是课程 id** —— id 是扫描下标，
   增删目录会整体移位，用 id 会把记录串到别的课上）。
   `touchCourse` 写盘；冷启动扫描后合并回 courses。

3. **进度记到了错误的课**（真实 bug）：
   播完《小汤1》退回书架，书架把 `sel` 挪到焦点课程，播放页 `onDispose` 又存一次进度，
   于是「最近播放」被刷成健身课。
   修：新增 `AppState.playCourse`（进播放页时锁定），`saveProgress/touchCourse/loadProgress`
   一律用它，不再用会变的 `sel`。

* 冷启动后记录保留：hero《小汤1》，卡片排第一，最近播放 11-07 21:03 → w2-coldstart

六、已知限制（如实记录，未处理）
--------------------------------
1. 收藏页 / 收藏左树里点**视频行**只弹 toast「播放：xxx」，不进播放页。
   `fpEnter` 只对 `#c`（课程目录里的集）走详情；目录下的散视频没有构造临时课程。
   影响：收藏一个目录后能浏览、能看列表，但要播放仍需走书架。
2. `Nav.kt` 里有两个重复的 `tag.startsWith("bt:")` 分支，第二个是死代码（不影响行为）。
3. 数据源编辑页仍会列出「这台主机的共享」，但语义已变成**可选**：
   留空 = 整机模式（全部共享进左树）；点一个共享 = 只显示那个共享。
   界面文案已按这个写明，但表单结构没有重排。
4. SMB 共享枚举依赖手写 srvsvc RPC（smbj 0.13 没有 listShares），
   报文结构是对着 jcifs-ng 的真实编码逐个字段对齐出来的，见 tv8.2 文档。
