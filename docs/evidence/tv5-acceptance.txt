4. 本轮修掉的缺陷清单（详见 docs/04 §tv5，共 15 类）
----------------------------------------------------------------
  1  全站假数据（Demo.kt：高等数学 / 线性代数 / 192.168.1.20 / 群晖 NAS）→ 删除文件，改真扫描
  2  TOTAL=12 写死 → Course.epCount / AppState.epCount()
  3  coursePathFor() 从没写入，所有课播同一目录 → epPath() 按真实文件取片源
  4  advance() 无调用点，单曲循环/自动下一节/连续播放空转 → 片尾轮询 + ExoPlayer repeatMode
  5  defaultSpeed 设置项从不生效 → resetPlayer() 应用
  6  doneEp 从不更新 → stepEp() / onPlaybackEnded() 更新
  7  时长 00:mm:ss 超 1 小时溢出；Track 在 totalSec=0 时除零 NaN → fmt() h:mm:ss + 保护
  8  数据源编辑只 toast / 重连假报「8 个顶层目录」/ 删除只删内存
     → 真表单 / 真重扫 / SourceStore.clear() + user_cleared 防复活
  9  浏览页 PARENT 假目录表（math/gk/ky…）→ 真实相对路径栈 stackFor()
  10 收藏面包屑写死 \\192.168.1.20\收藏路线；弹窗加入书架只建空课程卡
     → cfg.uncOf() 真 UNC；复用 addToShelfByNode()
  11 顶栏写死 IP 与 20:41、表单占位 IP、关于页 v1.2.0 → 真实 host / 时钟 / 版本
  12 本地卡假「已就绪」、数据源卡「0 个顶层目录」→ 如实标注 + "N 项顶层内容"
  13 长课程名单行截断、浏览页不识别已在书架 → 固定两行 + inShelfPath()
  14 （防御性）连按快进以 250ms 才回填的 curSec 为基准，极端连按理论上会叠成一次；
     实测连按 8 次正常累加（全屏态步长 seekStep=10 秒，8×10=80 秒 + 自然播放，
     与 01:33 截图一致），**未复现丢步** → seekAccumMs 累加基准
  15 播放失败静默退回设备私有目录演示 mp4 → 删除该回退；扫描无反馈 → CatalogBanner

  另：删除 PlayerPage 里已不可达的「演示片源 · 本地」角标死代码。
