# 10 · 数据源输入与真实连接（P1 表单闭环）

日期：2026-11-05
前提：TV 端自带输入法（本项目实测机型装的是搜狗 TV 版），焦点进入文本框时从底部弹出。
所以**不自绘软键盘**——重造一个 TV 软键盘既费时又比不过成熟 IME（词库、九宫格、语音）。

---

## 1. 核心难点：编辑态与导航态必须分开

TV 上没有触摸，遥控器方向键既要用作「区域导航」，又要用作「输入框内移动光标」。
两者混在一起就会出现经典故障：**在输入框里按方向键，光标不动、焦点却在页面上乱跳**。

解法是显式的两态：

| 态 | 谁处理按键 | 输入框是否存在 |
|---|---|---|
| 导航态（`addEditing == null`） | 我们的 `REG` 区域导航 | **不渲染** BasicTextField |
| 编辑态（`addEditing == "host"` 等） | 系统 IME + BasicTextField | 渲染并 `requestFocus()` |

两处关键实现：

1. **导航态完全不渲染输入框**。不是 `readOnly`、不是 `enabled=false`，而是不进组合树。
   只要输入框在树里且可聚焦，Compose 的焦点系统就会在某个方向键上抢走焦点。
2. **`handleKeyDown` 里编辑态直接 `return false`**（除了返回键），把按键全部放行给 IME：

```kotlin
if (addEditing != null) {
    if (back) { endEdit(); return true }
    return false          // 交给输入法/文本框
}
```

顺带在 `handleKeyUp` 里也放行，否则短按 OK 会触发一次 `activate()`。

## 2. 结束编辑的三条路径（都要有）

| 路径 | 触发 | 说明 |
|---|---|---|
| IME 的「完成 / 确定」 | `KeyboardActions(onDone)` → `endEdit()` | **TV 上的正常操作**，提示文案写的就是这个 |
| 键盘收起 | 监听 `WindowInsets.ime` 从有到无 → `endEdit()` | 用户按遥控器返回来收键盘时自动退编辑 |
| 返回键 | `endEdit()` | 退路 |

为什么需要第 2 条：IME 弹出后，第一次按遥控器返回通常**被输入法自己消费**（它只收键盘），
我们的 `handleKeyDown` 收不到事件；用户会以为「卡在输入框里出不来」。
监听 IME 高度变化可以自动补上这一步。

> ⚠️ 模拟器上的已知差异：MuMu 里搜狗 TV 键盘虽然 `mInputShown=true`，但**不渲染界面、
> IME inset 也不变**，所以第 2 条不触发，需要按两次返回。真机会正常。

## 3. 密码不能明文外露

`PasswordVisualTransformation` **只在输入框里生效**。退出编辑后我们渲染的是普通文本，
如果不处理，密码会以一个一个圆点以外的形式——**明文**——显示在电视上（实测截图确认过）。

```kotlin
val shown = if (isPwd && value.isNotEmpty()) "•".repeat(value.length.coerceAtMost(16)) else value
```

## 4. 「测试连接」改成真的连

之前是 `if (addHost.isNotEmpty()) "ok"` —— 只要填了主机就报"连接成功"，是纯占位。
现在：

```
后台线程 → SmbSession.connect(host, share, user, pwd) → list(root) → 真实条目数
```

结果分两类写回界面：

- 成功：`已连上 · \\10.0.2.2\课程共享\02 乐理课程（13门课）\张晖-乐理基础知识-入门篇(4061) 下有 12 项`
- 失败：按错误码翻成人话，而不是笼统的"连接失败"

| 分类 | 界面文案 |
|---|---|
| `auth` | 账号或密码不对（Windows 也要求输入正确密码） |
| `full` | 电脑那边 SMB 连接数已满，先清掉僵尸会话再试 |
| `network` | 连不上 host:port · 检查 IP、是否同一网段、电脑防火墙 |
| `path` | 共享「X」不存在，或没有访问权限 |

实测两条都验过：正确密码 → "连接成功 / 下有 12 项"；故意输错 → "账号或密码不对"。

## 5. 字段语义：一个「共享 / 路径」管两件事

原型只有 5 个字段（主机/端口/路径/账号/密码），没有单独的"共享名"。
约定：**路径的第一个路径段就是共享名，其余是共享内目录**。

```
课程共享                              → share=课程共享, root=""
课程共享/02 乐理课程（13门课）/张晖…  → share=课程共享, root=02 乐理课程（13门课）\张晖…
```

`AppState.splitPath()` 负责拆分，`SourceStore.Cfg.uriOf()` 负责拼回 `smb://`。

## 6. 配置必须持久化（本轮新修）

之前 `sources` 是纯内存的 Demo 列表，**杀进程就回到 4 张假卡片**，用户配好的共享等于白配。

现在：
- `SourceStore` 落盘 host/share/user/pass/root（SharedPreferences，App 私有目录）
- 启动时 `restoreRealSource()` 把它还原成一张卡片，并**在后台真连一次核实条目数**
- 连不上就标红并给出分类原因，不假装"已连接"

实测：重启后卡片显示 `10.0.2.2:445 · 课程共享/02 乐理课程 · 已连接 · 12 个顶层目录`，
数字来自真实 `list()`，不是硬编码（之前写死 6）。

## 7. 顺手做的体验优化

**预填上次配置**（不含密码）。TV 上敲一遍 IP + 中文共享名很痛苦，
换目录或改端口时不该从头再打一遍。进入添加页自动带上 `host/port/path/user`。

## 9. 仍未做

- ~~**编辑/删除已有数据源**：三个按钮不接逻辑~~ → **tv5 已修**，见 §10。
- **多数据源**：`SourceStore` 只存一条活动配置。多源需要 Room 表。
- **中文路径输入**：靠系统输入法（搜狗 TV 支持），但 `adb input text` 只能输 ASCII，
  所以自动化测试跑不了中文场景，这条只能人工在真机验（tv5 用预置快捷位置绕过）。
- **`adjustPan` 的观感**：TV 键盘从底部弹时窗口整体上移，字段不会被遮——但**真机上是否
  出现整页跳动没有实测**（模拟器键盘不渲染，测不出）。如果真机观感差，改 `adjustNothing`。
- **本地 U 盘 / SD 卡浏览**：数据源页的「本地数据」卡在 tv5 已如实标注「尚未实现」。

## 10. tv5 补记：默认真实共享、快捷位置与 CRUD 真动作

**默认配置**（`RealCatalog.DEFAULT_*`，仅在首次启动且用户从未主动删除过时写入）：
`192.168.1.10` / 共享 `课程共享` / 起始目录 `02 乐理课程（13门课）` / 账号密码均 `guest`。
预置理由：共享名与起始目录含中文和括号，TV 输入法手敲成本极高，且 `adb input text`
不能输中文；预置只是默认值，随时可在添加数据源页改掉。

**快捷位置**（`RealCatalog.shortcuts`）全部是本机核实存在的真实共享，且每条带真实密码
（`Endpoint.pass`）——此前 `fillFrom()` 把遮蔽圆点当密码送去认证，快捷位置一点必然失败：

| 快捷位置 | host / share / root |
|---|---|
| 课程共享 · 02 乐理课程 | `192.168.1.10` / `课程共享` / `02 乐理课程（13门课）` |
| 舞蹈共享 · 幼儿园舞蹈 | `192.168.1.10` / `舞蹈共享` / `幼儿园舞蹈` |
| 学习资料 · 乐理 | `192.168.1.10` / `学习资料` / `乐理` |
| 课程共享 · 共享根目录 | `192.168.1.10` / `课程共享` / 空 |

**CRUD 三件事现在都是真的**：

- 编辑 → 打开表单并灌回已存配置（含密码），不再只弹一句说明。
- 重连 → 调 `loadRealCatalog()` 真连 + 重扫，卡片状态由扫描结果决定；
  不再假报「重新连接成功 · 读到 8 个顶层目录」。
- 删除 → `SourceStore.clear()` 清持久化配置并写 `user_cleared` 标记，
  `ensureDefault()` 见到该标记就不把默认共享塞回去；否则杀进程重启数据源会「复活」。

**保存后一次扫描重建全部界面数据**（书架 / 剧集 / 浏览树 / 收藏根 / 数据源卡），
因此换共享后不会出现「卡片换了、书架还是旧课」的错位。实测从 `课程共享`
切到 `舞蹈共享` 后顶栏副标题、书架、集数同步变化，见 `docs/evidence/tv5-mumu-share2-shelf.png`。
