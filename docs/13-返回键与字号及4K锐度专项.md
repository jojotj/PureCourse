## 2. 问题 1：返回键完全失效（已修）

### 2.1 复现（电视 tv2，已验证）

```
for i in 1 2 3; do adb -s 192.168.1.11:5555 shell 'input keyevent 4'; done
→ 三次后 mResumedActivity 仍为 com.chunting.purecourse/.MainActivity，pid 23354 存活
```

### 2.2 根因（代码级，非推测）

`state/KeyRouter.kt:194`（修复前）：

```kotlin
if (back) { back(); return true }   // back() 的返回值被丢弃
```

`MainActivity.kt:70` 的退出闸门是 `if (!handled && Keys.isBack(code)) finish()`。
`back()` 的返回值语义本来就是「false = 没有更上层了，交给系统退出」，但这里被吞掉，
`handleKeyDown` 对 BACK **永远返回 true**，于是 `finish()` 永远不执行。

### 2.3 修复

```kotlin
if (back) return back()
```

## 3. 问题 2：补回「回顶栏」分级（已修）

### 3.1 原型依据（不是自创规则）

`前期准备/merged-shelf-list.html:3258` 的 `back()` 末尾：

```js
if (pg === 'settings'){ ... go('page-home', ...); setFocus(tabLanding(tb)); return; }
setFocus(curTabEl());     // ← 最后一级：焦点回到当前 Tab
```

`curTabEl()` 定义在 3052 行，返回 `.tab[data-tab="TABNAME"]`。Kotlin 移植时把首页这级
写成了 `return false`（直接退出），**漏还原了 curTabEl()**。用户第 2 点指出的正是这一级。

### 3.2 新分级（仅作用于书架 / 收藏 / 设置三页，其余页面保持原型）

| 页面 | 焦点在内容里 | 焦点已在顶栏 |
|---|---|---|
| 书架 | 回 `top:tab:shelf` | 返回 `false` → `finish()` 退出应用 |
| 收藏 | 先走原型内部分级（右列→左树→收起展开→上级→归零），分级到底后回 `top:tab:fav` | 返回 `false` → 退出应用 |
| 设置 | 回 `top:set` | 按原型回进入设置前的 Tab 页，焦点落 `tabLanding(tb)` |

- 收藏页内部分级**保留**，不能一次跳过，否则会破坏原型 `.fp-tip`「← 返回上级」那套树交互。
- Android 侧比网页多一级「退出」：顶栏再按一次返回才 `finish()`，避免误按直接退出。

### 3.3 顺带修正的移植偏差（需用户过目）

`state/AppState.kt:68` 冷启动焦点原本硬编码 `top:tab:shelf`，与
`defaultFocus()`（`Page.Home → hero`）及原型 `pageDefault('page-home') = tabLanding(TABNAME)`
都矛盾。若不改，装上新包**第一下按返回就直接退出**，用户会误以为分级没生效。
已改为 `hero`。这是本轮唯一一处「用户未点名」的改动，按原型对齐，特此单列。

## 5. 问题 4：字体为什么发虚（结论：不是 App 渲染 bug）

### 5.1 硬件层原始证据（电视，已验证）

```
$ adb -s 192.168.1.11:5555 shell getprop | grep vendor.display-size
[vendor.display-size]: [3840x2160]                 ← 物理面板 4K

$ adb ... shell wm size; wm density
Physical size: 1920x1080
Physical density: 240                             ← Android 只给 App 1080p 画布

$ adb ... shell dumpsys SurfaceFlinger | grep -E '3840|LayerW|DstW|w/h'
3840 x 2160 | 3840 x 2160 | 120 | 1920 x 1080 |
LayerW:LayerH|DstW:DstH[0:0|1920:1080|3840:2160]  ← HWC 明确放大 2 倍
name:com.chunting.purecourse/.MainActivity#0 ... w/h:1920x1080
```

### 5.2 回答用户的疑问

> "矢量字体理论上 4K 和 1080P 清晰度应该一样呀"

**这个理解本身是对的，但前提不成立**：矢量字体的锐度只取决于「栅格化那一刻是否与输出像素 1:1」。
这台电视的链路是：

```
Compose 文字 (矢量)
  → 按系统告知的 1920×1080 画布栅格化成像素       ← 锐度在此决定，此处是干净的
  → MTK HWC 把整张 1080p 位图放大到 3840×2160     ← 双线性/多相插值，笔画边缘被抹成灰阶
  → 4K 面板显示
```

即「矢量化之后又被位图放大了一次」。App 通过 `DisplayMetrics` 只能拿到 1920×1080，
**无法知道面板是 4K，也无法输出 4K framebuffer**，所以这不是 App 能通过改代码消除的模糊。

- **已验证**：framebuffer 与 App 图层均为 1920×1080；HWC Dst 为 3840×2160；
  `screencap` 抓到的放大前原始帧里文字笔画是正常硬边 / 常规抗锯齿（`docs/tv-141-text-zoom4x.png`）。
- **推断**（未用相机拍屏幕，故标为推断）：用户在电视上看到的「发虚」是上述 2× 插值的结果，
  同一台电视上的其他 App 系统文字同理。
- **不是原因**：StageCanvas 的 `LocalDensity` 重映射（它按当前画布密度重新排版描字，没有
  先画位图再拉伸）；`screencap` 压缩（PNG 无损）。

### 5.3 能实际改善的办法

| 办法 | 归属 | 本轮是否做 |
|---|---|---|
| 放大字号：笔画在 1080p 层占更多像素，放大后灰阶占比相对更小 | App | ✅ 已做（24/20/14、书架 20/13） |
| 全站 `fontScale` 旋钮：`StageCanvas` 里 `Density(fit, 1f)` 的 `1f` 提到 1.1~1.15，等比放大全部 `.sp` 文字而不改 `.dp` 布局 | App | ❌ 未做，待用户选（可能局部溢出） |
| 电视「图像模式」设电脑/游戏、关降噪与动态平滑，减少后处理抹字 | 电视设置 | ❌ 未动 |
| 若 ROM 有「4K UI / 高分辨率界面」开关，让系统按 3840×2160 渲染 | 电视系统 | ❌ 未动；**不擅自改系统分辨率**（MuMu 竖屏事故教训） |
| 焦点卡片 `graphicsLayer scale(1.035)` 会让该卡片文字二次重采样，属次要叠加 | App | ❌ 未改，原型 `.book.focused{transform:scale(1.035)}` 明确要求 |

## 6. 安装通道：又排除了一种（已验证）

`docs/11` 已记录 `adb install` / `pm install` / `--skip-verification` /
`package_verifier_enable=0` / `verifier_verify_adb_installs=0` 全部失败。本轮新增两次尝试：

```
adb push tv3.apk /sdcard/Download/purecourse-tv3.apk        ✅ 成功
am start -a VIEW -d file:///sdcard/Download/... -t application/vnd.android.package-archive
  → No activity found（Android 7+ 已移除 file:// 安装入口）
content query --uri content://media/external/file → _id=5442
am start -a VIEW -d content://media/external/file/5442 -t application/vnd.android.package-archive
  → com.android.packageinstaller/.InstallStart 能解析，但界面静默消失、
    无安装 UI、版本仍为 tv2
```

结论收窄为：**TCL 在 PackageManager 验证环节封掉了全部 ADB/shell 侧安装通道**，
包括系统安装器 intent。唯一可用仍是 **U 盘 + 电视自带安装器**，或换手机 `adb install`。
tv3 已推到电视 `/sdcard/Download/purecourse-tv3.apk`，也可在电视文件管理器里直接点开尝试。
